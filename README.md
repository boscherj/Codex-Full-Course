# Codex

Ce repository rassemble les informations, notes et ressources utiles pour un cours sur **Codex**.

## Objectif

Centraliser dans un seul endroit les contenus nécessaires pour préparer, structurer et enrichir un cours autour de Codex :

- notes de veille
- résumés de fonctionnalités
- documents de référence
- exemples et supports de cours

## Contenu

Le contenu de ce dépôt a vocation à évoluer au fil du cours et des nouveautés liées à Codex.
