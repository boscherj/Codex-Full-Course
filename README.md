# Cours complet sur GitHub Copilot Codex

Bienvenue dans ce cours complet sur **GitHub Copilot Codex**, l'agent de programmation IA développé par GitHub et OpenAI. Ce cours est conçu pour les développeurs souhaitant maîtriser l'utilisation de Codex dans leur flux de travail quotidien.

## 📚 Structure du cours

| Module | Titre | Durée estimée |
|--------|-------|---------------|
| 01 | [Introduction à Codex](modules/module-01-introduction.md) | 1h |
| 02 | [Installation et configuration](modules/module-02-configuration.md) | 1h |
| 03 | [Utilisation de base](modules/module-03-utilisation-de-base.md) | 2h |
| 04 | [Fonctionnalités avancées](modules/module-04-fonctionnalites-avancees.md) | 2h |
| 05 | [Bonnes pratiques et éthique](modules/module-05-bonnes-pratiques.md) | 1h |

## 🎯 Objectifs pédagogiques

À la fin de ce cours, les participants seront capables de :

1. **Comprendre** les fondements de l'IA générative appliquée au code
2. **Configurer** GitHub Copilot dans leur environnement de développement
3. **Utiliser** Copilot pour accélérer l'écriture de code
4. **Tirer parti** des fonctionnalités avancées comme Copilot Chat et l'agent de codage
5. **Appliquer** les bonnes pratiques pour une utilisation responsable et efficace

## 📋 Prérequis

- Notions de base en programmation (un langage au choix)
- Compte GitHub (gratuit)
- Visual Studio Code installé (recommandé)
