# Dernières innovations de Codex Desktop

Au 30 avril 2026, les nouveautés les plus récentes de **Codex Desktop** (désormais appelé **Codex app**) sont surtout celles-ci :

- **GPT-5.5 dans Codex** depuis le **23 avril 2026** : nouveau modèle recommandé pour les tâches complexes de code, debug, refactor et validation.
- **Utilisation du navigateur intégrée dans l’app** : Codex peut désormais interagir avec des serveurs locaux et des pages fichier pour vérifier une UI ou reproduire un bug visuel.
- **Automatic approval reviews** depuis le **23 avril 2026** : certaines demandes d’élévation peuvent passer par un agent relecteur automatique avant exécution.
- **In-app browser + “computer use”** depuis le **16 avril 2026** : Codex peut commenter une page rendue et, selon le cas, piloter des apps macOS en voyant, cliquant et tapant.
- **Chats sans projet** : possibilité d’ouvrir des threads orientés recherche, rédaction, planification ou analyse sans choisir un dossier de code au départ.
- **Plugins** depuis le **25 mars 2026** : installation de bundles réutilisables regroupant skills, intégrations d’apps et configuration MCP.
- **Automations remaniées** depuis le **12 mars 2026** : exécution locale ou sur worktree, choix du modèle, du niveau de raisonnement et utilisation de templates.
- **Lecture du terminal intégré** depuis le **11 mars 2026** : Codex peut relire la sortie d’un serveur de dev ou d’un build raté pendant qu’il travaille.
- **Version Windows** depuis le **4 mars 2026** : app native Windows avec PowerShell et sandbox native, sans passer par WSL.

En pratique, le gros virage récent est que Codex Desktop n’est plus juste une interface de chat pour coder : c’est devenu un **poste de pilotage multi-agents**, avec **worktrees**, **skills**, **automations**, **navigateur intégré**, **plugins** et **supervision plus fine des permissions**.
